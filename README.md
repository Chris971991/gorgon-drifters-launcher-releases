# Gorgon Drifters Launcher

The launcher for the Gorgon Drifters Valheim server. It sets up the same mods the server runs, keeps them matched, and puts you straight into the server with one press of Play.

## Install

1. Open the [latest release](https://github.com/Chris971991/gorgon-drifters-launcher-releases/releases/latest).
2. Download `Gorgon-Drifters-Launcher-Setup-<version>.exe` and run it.
3. If Windows shows "Windows protected your PC", press **More info**, then **Run anyway**.

The launcher keeps itself up to date. When a new version has downloaded, an **Update** button appears at the bottom left; press it to restart into the new version.

The portable `.exe` runs without installing, but it doesn't update itself. Use the setup file unless you have a reason not to.

## What it does

- Installs and matches the server's mods in its own Valheim profile (your normal Valheim is left alone)
- Play goes straight into the server as the Viking you pick
- Your Vikings: stats, skills, gear, and an editor for items and skills
- World map with your explored area, guild pins and who's online
- Who's on, the server's settings, and asking to join the guild
